# 📖 金剛般若波羅蜜經　互動閱讀網頁

---

## 🌟 專案簡介

本專案將《金剛經》（鳩摩羅什版，全32品）製作成**互動式網頁**，採用古典禪意風格設計。

**核心功能：**
- 左欄顯示原文，逐句可點擊
- 右欄即時顯示對應的白話翻譯，並有淡入動畫
- 每一品皆有前後品的導航連結，可連續閱讀
- 響應式設計，電腦與手機皆可使用

**閱讀方式：**
點擊左側任何一句原文 → 右側立即出現白話解釋 → 點擊空白處清除

- **背景色**：米色（`#f5f0e8`），呈現古典宣紙質感
- **字體**：Noto Serif TC，接近傳統毛筆書法風格
